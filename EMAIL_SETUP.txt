AI VIRTUAL RECEPTIONIST DEMO FORM EMAIL DELIVERY
==================================

IMPORTANT: The demo form is designed so your personal inbox address is NOT
written into the public website HTML or browser JavaScript.

DESTINATION INBOX
-----------------
In Cloudflare Pages, set the LEADS_TO_EMAIL variable to:

hisjarman@gmail.com

WHERE TO SET IT
---------------
1. Open Cloudflare Dashboard.
2. Go to Workers & Pages.
3. Select your AI Virtual Receptionist Pages project.
4. Open Settings, then Variables and Secrets.
5. Add LEADS_TO_EMAIL with value hisjarman@gmail.com.
6. Add RESEND_API_KEY as an encrypted Secret (get this from Resend).
7. Add LEADS_FROM_EMAIL with a sender address verified in Resend, such as
   leads@aivirtualreceptionist.online.
8. Save and redeploy the project.

RESEND DOMAIN VERIFICATION
--------------------------
Resend must verify the sending domain before it can send from
leads@aivirtualreceptionist.online. Follow Resend's domain setup and add the DNS records
it gives you to your domain's DNS settings.

HOW IT WORKS
------------
The public form sends the submitted business details to the private-side
Cloudflare Pages Function at /api/lead. That function sends the email through
Resend to the LEADS_TO_EMAIL value stored in Cloudflare.

The /api/lead route is a backend endpoint. It does not reveal your Gmail
address to website visitors. Do not put your Gmail address or Resend API key
in index.html, demo/index.html, or public JavaScript.

NO EMAIL WILL ARRIVE UNTIL THE CLOUDFLARE VARIABLES/SECRET AND RESEND SENDER
DOMAIN ARE CONFIGURED. This folder alone does not configure your live account.
